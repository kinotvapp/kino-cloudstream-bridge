# GPL-3.0 (this fork). Baseline profile, written by hand (upstream has no Macrobenchmark / baseline-profile module to
# generate one from). The cold path Kino waits on: process start, bind, hello, the first op loading a stored plugin
# (index read, ABI check with dexlib2, plugin class loading), and the NiceHttp client every plugin request goes through.
# AGP merges this into assets/dexopt/baseline.prof; androidx.profileinstaller (already in the APK) installs it on
# sideloaded devices. Task 9 part B measures cold bind with and without it (target: hello within 400 ms on the Fire TV).
